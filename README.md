# ТравелЕк

Дневник маршрутов: https://travelek.layero.app

## Что выбрать в Layero

Не файл. Репозиторий целиком.

| Поле | Значение |
| --- | --- |
| Репозиторий | `morrfi03/Travelek` |
| Ветка | `main` |
| Корневая папка | пусто, это корень репозитория |

Если форма всё же требует один файл — `index.html` в корне. Не `src/travelek.js`, не файлы из `src/parts/` и не `package.json`.

Сборка Vite не нужна и её нельзя включать: Layero отдаёт корень как есть (`layero.json`, режим static). `package.json` в репозиторий не класть.

Части дневника склеиваются так: `node build.mjs`. На сайт уходит уже готовый `src/travelek.js`. Страница грузит файлы сама через `src/main.js`.

## Как разложено

| Путь | Зачем |
| --- | --- |
| `index.html` | Страница, её и открывает сайт |
| `src/main.js` | Точка входа, обычные файлы без сборщика |
| `src/travelek.js` | Дневник, его собирает `node build.mjs` |
| `src/parts/` | Тот же дневник, разрезанный на части |
| `src/places.worker.js` | Индекс городов, не в потоке карты |
| `src/atlas.js` | Карта и глобус |
| `geo/` | Границы, дороги, справочник |
| `art/` | Картинки |

Аккаунты и маршруты в git не лежат.
