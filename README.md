# ТравелЕк

Дневник маршрутов: https://travelek.layero.app

Layero публикует репозиторий как статический сайт. Сейчас хостинг открывает корневой `index.html`; изменения в `src/` сами по себе не попадают в опубликованную страницу.

## Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Опубликованная страница сайта |
| `art/` | Картинки интерфейса |
| `geo/` | Геометрия стран и регионов России |
| `vendor/` | Leaflet и d3 |
| `src/markup.html` | Исходная разметка |
| `src/travelek.js` | Исходная логика карты, маршрутов и аккаунтов |
| `favicon.svg` | Иконка вкладки |
| `og.jpg` | Картинка предпросмотра ссылки |

## Хранение данных

Целевой режим — локальное хранение в браузере. Маршруты и аккаунты не должны отправляться в удалённое хранилище. Данные локальны для конкретного браузера и устройства, не синхронизируются автоматически между устройствами и могут быть потеряны при очистке данных браузера.

**Важно:** корневой `index.html` — отдельная собранная страница. Перед публикацией изменений из `src/` необходимо перенести их в `index.html` или настроить сборку, иначе сайт продолжит использовать старую версию.
