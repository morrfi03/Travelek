# ТравелЕк

Дневник маршрутов: https://travelek.layero.app

## Что выбрать в Layero

Не файл. Репозиторий целиком.

| Поле | Значение |
| --- | --- |
| Репозиторий | `morrfi03/Travelek` |
| Ветка | `main` |
| Корневая папка | пусто, это корень репозитория |

Если форма всё же требует один файл — `index.html` в корне. Не файлы из `src/parts/` и не `package.json`.

Сборка Vite не нужна и её нельзя включать: Layero отдаёт корень как есть (`layero.json`, режим static). `package.json` в репозиторий не класть.

Дневник не склеивается в один файл. Страница через `src/main.js` грузит части по очереди. Проверка синтаксиса: `node build.mjs`.

## Как разложено

| Путь | Зачем |
| --- | --- |
| `index.html` | Страница, её и открывает сайт |
| `src/main.js` | Точка входа, грузит части дневника по очереди |
| `src/parts/01-catalog.js` | Справочники: города, аэропорты, встроенные маршруты |
| `src/parts/02-cloud.js` | Вход и сохранение дневника |
| `src/parts/03-roads.js` | Дороги и линии маршрутов |
| `src/parts/04-app.js` | Экран: список, карта, поездки |
| `src/places.worker.js` | Индекс городов, не в потоке карты |
| `src/atlas.js` | Карта и глобус |
| `geo/` | Границы, дороги, справочник |
| `art/` | Картинки |

Аккаунты и маршруты в git не лежат.
