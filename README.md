# ТравелЕк

Дневник маршрутов: https://travelek.layero.app

Layero публикует репозиторий как статический сайт. Открывается файл `index.html` в корне.

## Как разложено

| Путь | Зачем |
| --- | --- |
| `index.html` | Страница: стили и разметка |
| `art/` | Картинки интерфейса |
| `geo/` | Карта, границы стран и регионов, дороги и железные дороги |
| `vendor/` | Leaflet и d3 — запасной путь, если своя карта не открылась |
| `src/gate.js` | Экран входа |
| `src/accounts.js` | Список аккаунтов администратора |
| `src/atlas.js` | Карта и глобус |
| `src/travelek.js` | Дневник: маршруты, страны, сохранение |
| `favicon.svg` | Иконка вкладки |
| `og.jpg` | Картинка для превью ссылки |

Аккаунты и маршруты в git не лежат. Их создаёт администратор на сайте, данные остаются у человека в браузере и в общем хранилище.
