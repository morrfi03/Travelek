# ТравелЕк

Дневник маршрутов: https://travelek.layero.app

Layero собирает репозиторий (`npm run build`) и публикует папку `dist`. Настройки — в `layero.json`.

Исходник дневника разрезан на `src/parts/` и собирается в `src/travelek.js`. Карта по-прежнему canvas, не React. Справочник городов считается в `src/places.worker.js`, не в потоке карты.

Отдельное хранилище — папка `worker/` (Cloudflare Worker и D1). Пока оно не подключено, дневники пишутся в прежний общий бин, чтобы ничего не потерять.

## Как разложено

| Путь | Зачем |
| --- | --- |
| `index.html` | Страница: стили карты и разметка |
| `src/parts/` | Дневник по частям: справочник, облако, дороги, карта |
| `src/travelek.js` | Сборка этих частей, её открывает страница |
| `src/places.worker.js` | Индекс городов и аэропортов |
| `worker/` | Будущий API: один дневник на человека |
| `art/` | Картинки интерфейса |
| `geo/` | Границы, дороги, справочник |
| `vendor/` | Leaflet и d3 |

Аккаунты и маршруты в git не лежат.
