# ТравелЕк

Дневник маршрутов: https://travelek.layero.app

Layero собирает репозиторий (`npm run build`) и публикует папку `dist`. Настройки — в `layero.json`.

Страница по-прежнему обычный `index.html` и скрипты без модулей. Сборка только копирует их в `dist`, чтобы хостинг не отдавал корень репозитория вслепую. Карта и дневник пока не переписаны.

## Как разложено

| Путь | Зачем |
| --- | --- |
| `index.html` | Страница: стили карты и разметка. Скрипты и картинки не вшиты, а подключены |
| `art/` | Картинки интерфейса |
| `geo/` | Границы стран и регионов России |
| `vendor/` | Leaflet и d3 |
| `src/markup.html` | Разметка экрана |
| `src/gate.js` | Экран входа |
| `src/travelek.js` | Логика дневника: карта, маршруты, аккаунты |
| `favicon.svg` | Иконка вкладки |
| `og.jpg` | Картинка для превью ссылки |

Аккаунты и маршруты в git не лежат. Их создаёт администратор на сайте, данные остаются у человека в браузере и в общем хранилище.
