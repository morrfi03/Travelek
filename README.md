# ТравелЕк

Дневник маршрутов: https://travelek.layero.app

## Что выбрать в Layero

Не файл. Репозиторий целиком.

| Поле | Значение |
| --- | --- |
| Репозиторий | `morrfi03/Travelek` |
| Ветка | `main` |
| Корневая папка | пусто, это корень репозитория |

Если форма всё же требует один файл — `index.html` в корне. Не файлы из `src/` и не `package.json`.

Сборка Vite не нужна. `package.json` в репозиторий не класть.

Сайт запускается как runtime: `node server.js` отдаёт те же файлы и `/api/flights`. Ключ расписания задаётся в Layero → Environment Variables, имя `AERODATABOX_KEY`. В git его нет. После сохранения переменной нужен новый деплой.

Дневник не склеивается в один файл. Страница открывает `src/main.js`. Справочник, облако, дороги и экран — обычные модули и импортируют друг друга. Карта рисует линии сама, без обёртки Leaflet. Проверка синтаксиса: `node build.mjs`.

## Как разложено

| Путь | Зачем |
| --- | --- |
| `index.html` | Страница, её и открывает сайт |
| `src/main.js` | Точка входа |
| `src/catalog.js` | Справочники: города, аэропорты, встроенные маршруты |
| `src/cloud.js` | Вход и сохранение дневника |
| `src/roads.js` | Дороги и линии маршрутов |
| `src/app.js` | Экран: список, карта, поездки |
| `src/places.worker.js` | Индекс городов, не в потоке карты |
| `src/atlas.js` | Карта и глобус |
| `geo/` | Границы, дороги, справочник |
| `art/` | Картинки |

Аккаунты и маршруты в git не лежат.
